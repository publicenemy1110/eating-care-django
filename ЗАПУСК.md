# Как запустить Eating Care (Django)

## Важно

Запускайте **этот** проект (`eating-care-django`), а не статический HTML с рабочего стола.

| Что открывать | Результат |
|---------------|-----------|
| `Desktop/html-css project/tests.html` в браузере | Кнопки «Открыть» ведут на `#` — тесты **не работают** |
| Django `runserver` (ниже) | Тесты открываются и проходятся |

## Запуск в PyCharm или терминале

```bash
cd ~/PycharmProjects/eating-care-django
source .venv/bin/activate
python manage.py migrate
python manage.py runserver
```

Откройте в браузере: **http://127.0.0.1:8000/tests/**

Пример теста: http://127.0.0.1:8000/tests/scoff/

После изменений в коде **перезапустите** сервер (Ctrl+C, снова `runserver`).

Обновите страницу с полным сбросом кэша: **Cmd+Shift+R** (Mac) или **Ctrl+Shift+R** (Windows).

Если опросник всё ещё без оформления: в Safari откройте **Разработка → Очистить кэши** (или перезапустите `runserver`) и проверьте, что в исходном коде страницы есть строка `screening.css` в `<head>`.

## Проверка

```bash
python manage.py test pages
```

Должно быть: `OK` (12 тестов).
